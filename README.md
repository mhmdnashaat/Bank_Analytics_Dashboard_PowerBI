# 🏦 Bank Analytics Dashboard | Power BI

## 📌 Overview

This project is an interactive Power BI dashboard designed to analyze banking operations and transform raw data into actionable business insights.

The dashboard covers five key business areas:

- Customers

- Transactions

- Loans

- Cards

- Support Calls

It also includes a dedicated Active Accounts Analysis for the last 500 days to monitor customer engagement.

---

## 🛠 Tools & Technologies

- Power BI Desktop

- Power Query

- DAX

- Data Modeling

- Drill Through

- Interactive Maps

- PowerPoint (UI Design)

---

## 📊 Key KPIs

- 5,050 Customers

- 20,000 Transactions

- $100.1M Transaction Amount

- $254.7M Total Balance

- $644.3M Loan Portfolio

- 4,000 Cards

- 95.3% Active Cards

- 3,100 Support Issues

- 50.68% Resolution Rate

---

## 🔍 Key Insights

- More than 81% of customer accounts are dormant.

- Active Accounts Analysis tracks customer activity over the last 500 days.

- Around 75% of the loan portfolio remains active.

- Business Loans contribute only $7.1M, highlighting growth potential.

- Transaction Disputes and Account Access generate the largest number of support requests.

- The current support resolution rate indicates opportunities to improve service efficiency.

---

## 💡 Business Recommendations

- Launch targeted campaigns to reactivate dormant customers.

- Expand the Business Loan portfolio.

- Prioritize high-volume support issues to improve resolution performance.

- Launch proactive card renewal campaigns.

- Monitor active customer behavior continuously using the 500-day analysis.
